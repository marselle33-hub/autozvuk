# Автозвук

Проверка и настройка автомобильной аудиосистемы с телефона.

- `index.html` — сама страница. Открывается в Safari и внутри приложения:
  https://marselle33-hub.github.io/autozvuk/
- `app/` — приложение для iPhone: оболочка, которая открывает страницу и берёт звук на себя,
  чтобы iOS не уводил звук с провода AUX на динамик телефона.
- Приложение собирается автоматически на GitHub при изменениях в `app/`.
  Последняя сборка: https://github.com/marselle33-hub/autozvuk/releases/download/latest/AutoZvuk.ipa
